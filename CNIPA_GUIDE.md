# 瑞通商标注册指南 — CNIPA Online Filing Guide
**商标注册网上申请步骤** (for 中山三角镇 / Zhongshan Sanjiao)

---

## ⚠️ Before You Start — 前提条件

**IMPORTANT: You need a 个体工商户营业执照 (Individual Business License)**

Since 2016, CNIPA requires individual applicants to hold an **individual business license** (个体户营业执照). A China Resident ID alone is not enough.

**How to get one (simple):**
- Go to your local 市场监督管理局 (Market Supervision Bureau) in 中山三角镇
- Or use the 粤省事 (Yueshengshi) WeChat mini-program / app
- It's cheap (~50-100 CNY), fast (same-day in many cities), and you just need your ID card
- Address can be your home in 中山三角镇

**If you don't want to get a license:** Use a trademark agency for ~500-1,000 CNY total — they handle the license requirement for you.

## Step-by-Step Online Filing (中文 + English)

### Step 1: Go to the Website (打开网站)
**URL:** [https://sbj.cnipa.gov.cn/sbj/index.html](https://sbj.cnipa.gov.cn/sbj/index.html) — 中国商标网

Click: **"网上申请"** (Online Application) in the top menu.

Or go directly: [https://sbj.cnipa.gov.cn/sbj/wssq/](https://sbj.cnipa.gov.cn/sbj/wssq/)

### Step 2: Register an Account (注册账号)

On the login page, click: **"用户注册"** (User Registration)

You'll need:
| Field | What to enter |
|-------|--------------|
| 用户名 Username | Pick something (e.g., `ruitong2026`) |
| 密码 Password | Create one |
| 姓名 Name | Your full name as on ID card |
| 证件类型 ID Type | **居民身份证** (Resident ID) |
| 证件号码 ID Number | Your 18-digit ID number |
| 手机号码 Phone | Your China Mobile number → receives SMS code |
| 邮箱 Email | Use your email |
| 用户类型 User Type | Select **"申请人"** (Applicant) |
| 地址 Address | 广东省中山市三角镇[your street/area] |

**After registering:** You'll get a verification SMS. Enter the code to activate.

### Step 3: Log In (登录)

Use your username + password to log into the **商标网上服务系统** (Trademark Online Service System).

### Step 4: Do a Search First (先查询确认可用)

Before filing, search to confirm 瑞通 is available:

1. Go to the search page: [http://sbj.cnipa.gov.cn/sbj/sbcx/](http://sbj.cnipa.gov.cn/sbj/sbcx/)
2. Click **"商标综合查询"** (Comprehensive Search)
3. Enter: **瑞通** in the 商标名称 (Trademark Name) field
4. Set 国际分类 (International Class) to **09** → check results
5. Then repeat for class **42**
6. If no identical/similar marks exist in Classes 9 and 42 → you're clear

### Step 5: Start a New Application (开始申请)

From the main system dashboard, click: **"商标注册申请"** (Trademark Registration Application)

### Step 6: Fill in the Application (填写申请书)

#### A. Applicant Info (申请人信息)
| Field | Value |
|-------|-------|
| 申请人名称 Name | Your full name |
| 申请人地址 Address | 广东省中山市三角镇[具体地址] |
| 证件号码 ID No. | Your 18-digit Resident ID |
| 联系人 Contact | Your name |
| 联系电话 Phone | Your China Mobile number |
| 邮编 Postal Code | 528400 (Zhongshan) |

#### B. Upload Required Documents (上传材料)
| Document | Format |
|----------|--------|
| **身份证正面** (ID front) | JPG/PNG, <2MB |
| **身份证反面** (ID back) | JPG/PNG, <2MB |
| **个体工商户营业执照** (Business License) | JPG/PNG, <2MB |

#### C. Trademark Info (商标信息)
| Field | Value |
|-------|-------|
| 商标名称 Name | **瑞通** |
| 商标类型 Type | **普通商标** (Regular Trademark) |
| 商标图样 Image | Upload the 瑞通 logo/text image. |
| 商标说明 Description | 无含义 (No meaning) — or write "瑞为吉祥之意，通为通达之意" |

**Preparing the logo file:**
- Create a simple image: black text "瑞通" on white background
- Size: 400×400 pixels min, JPG or PNG
- Save as `ruitong-logo.jpg`

#### D. Select Classes (选择商品/服务项目)

**Class 9** — Select these items (pick ✓ the ones that apply):

| 中文 | English |
|------|---------|

| 可下载的计算机应用软件 | Downloadable computer application software |
| 可下载的手机应用软件 | Downloadable mobile phone apps |
| 数据处理设备 | Data processing equipment |
| 计算机硬件 | Computer hardware |
| 芯片（集成电路） | Chips (integrated circuits) |
| 半导体器件 | Semiconductor devices |
| 应用程序编程接口（API） | Application Programming Interface (API) |
| 用于人工智能的计算机软件 | Computer software for AI |
| 区块链技术软件 | Blockchain technology software |

**Class 42** — Select these items:

| 中文 | English |
|------|---------|
| 软件即服务（SaaS） | Software as a Service |

**Tip:** CNIPA allows 10 items per class for the base fee (270 CNY). Pick your 10 most important ones. Extra items cost 27 CNY each.

### Step 7: Review and Submit (核对并提交)

Double-check everything:
- [x] Name: 瑞通
- [x] Applicant name matches your ID
- [x] Address matches your 营业执照
- [x] Classes: 9 and 42 selected
- [x] Items: 10 or fewer per class
- [x] Documents uploaded (ID + 营业执照)
- [x] Logo file uploaded

Click **"提交"** (Submit)

### Step 8: Pay the Fee (缴费)

Total: **270 CNY × 2 classes = 540 CNY**

Payment methods:
- **在线支付** (Online payment) — Alipay / WeChat Pay / Bank card
- Must pay **within 24 hours** of submission, otherwise the application is cancelled

### Step 9: Wait for Examination (等待审查)

| Stage | Time | What happens |
|-------|------|-------------|
| 形式审查 Formal exam | ~15 days | CNIPA checks if documents are complete |
| 实质审查 Substantive exam | ~4 months | CNIPA checks for conflicts with existing marks |
| 初审公告 Publication | 3 months | If approved, published for public opposition |
| 核准注册 Registration | ~1 month | Certificate issued (electronic only) |

**Total time: ~8-9 months** from filing to registration.

## What to Watch For (注意事项)

**If your Chinese is limited:**

1. **Use browser translate** — Chrome can auto-translate the page (right-click → Translate to English)
2. **The CNIPA system is in Chinese only** — no English UI available
3. **Screen shot confusion** — If unsure at any step, screenshot and send to me. I'll tell you what to click next.
4. **SMS verification** — Make sure your China Mobile phone has signal and can receive SMS
5. **Save your application number** (申请号) — you'll need it to track progress

**Common rejection reasons to avoid:**
- Items too vague (e.g., "computer software" is OK; "all goods" is not)
- Logo too similar to existing marks → do the search first
- Wrong class → 9 = software/electronics, 42 = SaaS/cloud services

- They don't need your 营业执照 — they manage the requirement
- You just send them: your name, ID number, address, and the logo
